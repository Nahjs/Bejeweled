# 聊天室开发记录

## 1. 项目概述

本聊天室是基于Qt框架开发的一个简单的在线聊天系统,采用C/S(客户端/服务器)架构。主要实现了基本的文字聊天、用户在线状态显示等功能。

## 2. 技术栈

- 开发语言: C++
- 开发框架: Qt 5
- 网络通信: Qt Network模块(QTcpServer/QTcpSocket)
- 数据持久化: SQLite数据库
- 界面设计: Qt Designer

## 3. 系统架构

### 3.1 服务器端(ChatServer)
- 基于QTcpServer实现
- 负责处理多客户端连接
- 管理在线用户列表
- 转发消息给所有客户端

### 3.2 客户端(ChatClient)
- 基于QTcpSocket实现
- 与服务器建立TCP连接
- 发送和接收消息
- 处理用户界面交互

## 4. 消息同步机制

### 4.1 消息协议
采用简单的文本协议,每条消息包含两行:
- 第一行: 消息类型(如"MSGA"表示普通消息,"LGIN"表示登录消息)
- 第二行: 消息内容

### 4.2 消息类型
- LGIN: 登录消息
- MSGA: 普通聊天消息
- USER: 用户列表更新

### 4.3 同步流程
1. 客户端连接时:
   - 发送LGIN消息进行登录
   - 服务器广播用户加入消息
   - 服务器发送最新用户列表

2. 发送消息时:
   - 客户端发送MSGA类型消息
   - 服务器接收后广播给所有在线用户

3. 用户断开时:
   - 服务器检测到断开连接
   - 广播用户离开消息
   - 更新并广播新的用户列表

## 8. 开发难点及解决方案

### 8.1 多客户端连接管理
- 问题: 需要同时处理多个客户端的连接和消息
- 解决: 使用Qt的事件驱动机制,为每个客户端创建独立的socket对象

### 8.2 消息同步
- 问题: 确保所有客户端收到消息并保持同步
- 解决: 实现可靠的消息广播机制,服务器统一处理和转发

### 8.3 断线处理
- 问题: 客户端意外断开时的处理
- 解决: 通过socket的disconnected信号检测,及时清理资源并通知其他用户
